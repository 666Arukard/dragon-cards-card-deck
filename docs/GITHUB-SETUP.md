## Paket und Updates

Der Release enthält das installierbare ZIP, das identische `module.json` und
eine SHA-256-Prüfsumme. Das automatisch erzeugte GitHub-Quellarchiv ist kein
Ersatz für das Installationspaket. Neue Versionen erhalten eigene Tags und
ZIP-Adressen; die Manifest-Adresse bleibt stabil. Bestehende Weltdecks werden
durch Modulupdates nicht automatisch verändert.

Der Quellstand enthält 180 WebP-Dateien, native Kompendiumdaten, JSON-Metadaten,
Dokumentation und Prüfwerkzeuge. Keine Zugangsdaten, persönliche E-Mail-Adressen,
Entwicklungsabhängigkeiten oder ZIP-Archive gehören in die Git-Historie.
Eine `website.json` wird nicht benötigt; die Website wird manuell gepflegt.

## Prüfstand

Paketprüfungen sind in [TESTS.md](TESTS.md) dokumentiert. Daniel Brune bestätigt
auf Foundry 14.369 den Import aller drei Decks mit je 59 Karten und das Ziehen.
Weitere Aktionen wurden nicht einzeln protokolliert. Der separate Test mit
Spieler-Clients steht aus. Kein eigener Live-Test durch ChatGPT/Codex und keine
vollständige Abnahme aller Berechtigungsszenarien. Der Manifest-Eintrag
`compatibility.verified = "14.369"` beruht auf Daniels bestätigtem Praxistest.
